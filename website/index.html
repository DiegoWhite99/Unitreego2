Usuarios del sistema

Aquí puedes ver y administrar los usuarios que pueden acceder al sistema. El usuario admin es la cuenta principal (super root) y no se puede eliminar. Puedes añadir hasta 2 usuarios adicionales con los siguientes roles:

  • Operador — puede conectar y controlar el robot.
  • Observador — solo puede ver el estado del robot.
