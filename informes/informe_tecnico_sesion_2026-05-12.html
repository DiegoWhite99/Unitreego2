Diagnóstico y Resolución de Conexión WebRTC - Unitree Go2 Air

12 de Mayo de 2026

🎯 Objetivo

Diagnosticar y resolver el problema de conexión al robot Unitree Go2 Air vía WebRTC, permitiendo la comunicación entre el backend Flask y el dispositivo robótico.

🔍 Diagnóstico del Problema

Síntoma Inicial

Error reportado: El sistema no podía conectar al robot vía WebRTC
Código de error: ModuleNotFoundError: No module named 'unitree_webrtc_connect'

Análisis Realizado

  1. Revisión de dependencias: Se encontró que requirements.txt estaba incompleto
  2. Ejecución de test: Script scripts/01_test_connection.py reveló el error real
  3. Diagnóstico WebRTC: Después de instalar dependencias, el error fue más específico

Causa Raíz Identificada

El robot Unitree Go2 Air versión G1 ≥ 1.5.1 requiere autenticación mediante una clave AES-128 de 32 caracteres hexadecimales para establecer conexiones WebRTC seguras.
This robot speaks data2=3 (G1 ≥ 1.5.1) — the per-device AES-128 key is required to decrypt the LAN handshake. Pass aes_128_key=... (32 hex chars) to UnitreeWebRTCConnection.
