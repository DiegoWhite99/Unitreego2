3. Arquitectura de Agentes IA

3.1 Flujo Conversacional

Usuario ↓ POST /api/agente/chat ↓ api/agent.py::api_agente_chat() ├─ Recibe: mensaje + historial ├─ Invoca: core/agents/chat.py::chat() │ ├─ 1️⃣ VALIDACIÓN │ └─ Health check (LLM disponible) │ ├─ 2️⃣ DETECCIÓN DE VISIÓN │ └─ ¿Pregunta sobre "ver"? → Auto-trigger YOLO │ ├─ 3️⃣ CONSTRUCCIÓN DEL MENSAJE │ ├─ User text │ ├─ Imagen YOLO (si disponible) │ └─ Contexto de visión (si auto-triggered) │ ├─ 4️⃣ LLAMADA AL MODELO │ ├─ OpenAI: client.chat.completions.create() │ └─ Gemini: genai.GenerativeModel().generate_content() │ ├─ 5️⃣ EJECUCIÓN DE HERRAMIENTAS │ └─ dispatch() → Acciones del robot │ ├─ 6️⃣ SANITIZACIÓN │ └─ Remove meta-leaks, action blocks, etc. │ └─ 7️⃣ RESPUESTA └─ {"reply": "...", "actions": [...]} ↓ Frontend / Socket.IO

4. Sistema de Herramientas (Function Calling)

Archivo: core/agents/tools.py

4.1 Catálogo Completo de Herramientas

🎭 Gestos y Posturas

  • saludar: Alza una pata (saludo amigable)
  • sentarse: Se sienta de forma estable
  • levantarse: Se levanta desde sentada
  • acostarse: Se acuesta (StandDown)
  • recuperarse: Se recupera a posición de pie
  • corazon: Gesto de corazón con patas (cariñoso)

🚀 Movimiento

  • mover: Mueve en direcciones (adelante, atrás, izquierda, derecha, girar)
  • saltar_adelante: Salto frontal corto
  • menear_caderas: Gesto juguetón
  • parar: Detiene movimiento (parada suave)

👁️ Visión

  • mirar_alrededor: Resumen YOLO de objetos detectados

4.2 Parámetros de Herramientas (Ejemplo: mover)

{
  "name": "mover",
  "parameters": {
    "direccion": "adelante|atrás|izquierda|derecha|girar_izquierda|girar_derecha",
    "duracion_s": 0.5 a 5 segundos (opcional),
    "grados": ángulo de giro en grados (opcional)
  }
}

4.3 Dispatcher

Traduce nombres de herramientas a comandos Python reales:

dispatch("mover", {
  "direccion": "adelante",
  "duracion_s": 2.5
})
  ↓
move_robot(
  direccion="adelante",
  duracion_s=2.5
)
  ↓
robot_send_command(Move(x=0.4, y=0, z=0))

4.4 Diferentes Protocolos

Modelo Protocolo Soporte Nativo
OpenAI (gpt-*) Function Calling nativo ✅ Sí
Gemini (gemini-*) Google Tools API ✅ Sí
Gemma 1/2/3 JSON inline en bloques ```action ⚠️ Degradado
⚠️ Nota: Gemma 1-3 no soportan function calling nativo, por eso el sistema maneja JSON inline. Gemma 4+ usa Google Tools como Gemini.

5. Flujo Detallado de Ejecución

5.1 Caso: Usuario pregunta "¿Qué ves?"

1. POST /api/agente/chat
   {"message": "¿Qué ves?", "history": []}

2. Regex _VISION_QUERY_RE detecta palabra clave "ves"
   ✓ Coincide → AUTO-TRIGGER VISIÓN

3. look_around() ejecuta en paralelo
   YOLO analiza frames → "Detecté 1 persona, 2 sillas, 1 puerta"

4. Construye mensaje para modelo:
   - User: "¿Qué ves?"
   - Sistema: "Diver soy un perro..."
   - Visión: "Tu cámara ve: 1 persona, 2 sillas..."
   - Imagen: JPEG actual (si disponible)
   - Tools: Lista de herramientas disponibles

5. Llama al modelo (OpenAI o Gemini)

6. Modelo responde:
   "Veo 1 persona sentada y 2 sillas al frente. Interesante."

7. Sanitiza respuesta
   ✓ Remove "User asked...", "I analyzed...", etc.

8. Devuelve:
   {
     "reply": "Veo 1 persona sentada y 2 sillas al frente...",
     "actions": [
       {
         "name": "mirar_alrededor",
         "ok": true,
         "msg": "1 persona, 2 sillas, 1 puerta"
       }
     ]
   }

5.2 Caso: Usuario pide movimiento

Usuario: "Gira 90 grados a la derecha"

→ Modelo genera tool call:
  {
    "type": "function",
    "function": {
      "name": "mover",
      "arguments": {
        "direccion": "girar_derecha",
        "grados": 90
      }
    }
  }

→ dispatch() ejecuta:
  move_robot(
    direccion="girar_derecha",
    grados=90
  )

→ Calcula:
  duracion_s = (90° × π/180) / 0.7 rad/s × 1.05 = 2.37 segundos

→ Envía al robot:
  Move(x=0, y=0, z=0.7) durante 2.37 segundos

→ Respuesta:
  {
    "reply": "Girado 90 grados. Listo.",
    "actions": [{"name": "mover", "ok": true, "msg": ""}]
  }

7. Diagnóstico y Troubleshooting

7.1 Verificar Health del Agente

curl http://localhost:5000/api/agente/health

o en Python:
from core.agents.chat import health
print(health())

7.2 Errores Comunes

Error Causa Solución
"Falta google-generativeai" Librería no instalada pip install google-generativeai
"Falta OPENAI_API_KEY" Clave no configurada Editar config/config.py o $env:OPENAI_API_KEY
"El robot no está conectado" WebRTC no establecido Verificar IP robot en config.py
"Las herramientas no se ejecutan" Robot desconectado o modelo sin function calling Verificar conexión y modelo (OpenAI/Gemini recomendados)

7.3 Ver Logs del Agente

En la consola de terminal, busca líneas que empiezan con [AGENTE]:
