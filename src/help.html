Preguntas frecuentes

El robot no se conecta
Verifica: (1) Tu computador y el robot están en la misma red WiFi; (2) La IP que escribiste es correcta (pregúntale al administrador); (3) El robot está encendido. Si sigue fallando, reinicia el robot y prueba de nuevo.
El robot no responde a los comandos
Primero presiona ⚠ Parada de Emergencia. Luego desconecta y vuelve a conectar. Si el problema persiste, revisa si el estado "WebRTC" está en verde (Activa). Si está rojo, la conexión de video/audio se perdió.
Olvidé mi contraseña
Contacta al administrador del sistema (el usuario admin). Él puede editar tu cuenta desde la sección "Usuarios" y asignarte una contraseña nueva.
La interfaz se ve rara en mi celular
El sistema está optimizado para pantallas pequeñas, pero algunas funciones de control fino se usan mejor desde computador o tablet. Asegúrate de usar un navegador moderno (Chrome, Edge, Firefox o Safari actualizados).
